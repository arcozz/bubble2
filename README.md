# Middle Click Sparks + Tab Open Animations for Zen

Deux effets, indépendants l'un de l'autre :

1. **Étincelles au clic milieu** sur un lien (ou Ctrl+clic) : ton effet d'origine, inchangé.
2. **Animation à l'ouverture d'un onglet** : Mini aimant (défaut), Traînée, Étincelles seules ou Aléatoire.
   Les effets sont dessinés par-dessus la fenêtre et peuvent dépasser de la sidebar.

Un clic milieu sur un lien déclenche donc les deux : étincelles au curseur, explosion sur le nouvel onglet.

## Réglages
- Étincelles : nombre, longueur, épaisseur, distance, durée (comme avant).
- Onglet : case pour activer/désactiver, style d'animation, vitesse en % (100 = normal).
- Les onglets restaurés au démarrage ne sont pas animés.
- Si rien ne s'affiche : active **Debug**, ouvre la Console (Ctrl+Shift+J).
